# Приложение «tabel» — Табельный учёт

## 1. Назначение

Учёт рабочего времени сотрудников предприятия. Ведение табеля, расчёт отработанных часов, интеграция с турникетами, учёт отпусков, больничных и т.д.

---

## 2. Сущности (таблицы)

### 2.1. Сотрудник (`employee`)

| Поле         | Тип    | Примечание                  |
| ------------ | ------ | --------------------------- |
| `number`     | `text` | **unique**. Табельный номер |
| `lastName`   | `text` | Фамилия                     |
| `firstName`  | `text` | Имя                         |
| `middleName` | `text` | Отчество                    |

> Сотрудник — статическая запись. Все изменения статуса — через кадровые документы.

### 2.2. Кадровый документ (`document`)

Фиксирует изменения статуса сотрудника:

| Тип (`type`) | Действие                                               |
| ------------ | ------------------------------------------------------ |
| `hiring`     | Привязка сотрудника → подразделение + должность с даты |
| `dismissal`  | Прекращение действия записей с даты                    |
| `transfer`   | Смена подразделения и/или должности с даты             |

**Поля:**

- `type` — enum: `hiring`, `dismissal`, `transfer`
- `date` — дата вступления в силу
- `docNumber` — номер приказа (string)
- `employee (ref)`
- `department (ref)`
- `position (ref)`
- `updatedAt` — дата последнего изменения (хук drizzle)
- `updatedBy` — кто изменил (ссылка на user из auth)

> Фиксированный набор типов, не расширяется.

| `parent (ref)` | Самореференс, nullable → иерархия |

### 2.4. Должность (`position`)

| Поле   |
| ------ |
| `name` |

### 2.5. График работы (`schedule`)

Описание _одного рабочего дня_: точки входа/выхода/перерывов, отклонения, норма часов.

| Поле               | Тип         | Примечание                                                    |
| ------------------ | ----------- | ------------------------------------------------------------- |
| `name`             | `text`      | Название (например «Стандартный 8:00–17:00»)                  |
| `standardWorkTime` | `integer`   | **Норма на один рабочий день** (в минутах; например 480 = 8ч) |
| `weekDays`         | `integer[]` | Дни недели (1–7, 1 = ПН). Если `null` — любой день            |

**Точки графика** — `schedule_point`:

| Поле             | Тип       | Примечание                                   |
| ---------------- | --------- | -------------------------------------------- |
| `schedule (ref)` |           |                                              |
| `type`           | `text`    | `Entry` / `Exit` / `BreakStart` / `BreakEnd` |
| `time`           | `time`    | Эталонное время точки                        |
| `leftBound`      | `integer` | Левая граница отклонения (минуты)            |
| `rightBound`     | `integer` | Правая граница отклонения (минуты)           |

| Точка      | Эталон         | Левая гр.   | Правая гр.  |
| ---------- | -------------- | ----------- | ----------- |
| Entry      | ArrivalTime    | EntryLBound | EntryRBound |
| Exit       | DepartureTime  | ExitLBound  | ExitRBound  |
| BreakStart | LunchStartTime | BreakLBound | BreakRBound |
| BreakEnd   | LunchEnd       | BreakLBound | BreakRBound |

> **Округление:** если фактическое время попадает в `[time − leftBound, time + rightBound]` — округляется до эталона.

**Связь сотрудника с графиками** — `employee_schedule` (M:N):

| Поле                  | Примечание                 |
| --------------------- | -------------------------- |
| `employee (ref)`      |                            |
| `schedule (ref)`      |                            |
| `dateFrom` / `dateTo` | Период действия (nullable) |

> Дни недели — свойство графика. Если сотруднику нужен другой набор дней — создаётся новый график.

> **Выбор графика:** при нескольких на одну дату — выбирается наиболее подходящий по времени входа/выхода (балльная оценка).

### 2.6. Метка табеля (`day_mark`)

| Поле         | Тип    | Примечание                                                 |
| ------------ | ------ | ---------------------------------------------------------- |
| `name`       | `text` | Полное название                                            |
| `shortName`  | `text` | **unique**. Короткое обозначение                           |
| `code`       | `text` | **unique**. Код для отчётов                                |
| `category`   | `text` | Категория метки (определяет логику расчёта)                |
| `reportCode` | `text` | nullable. Внешний код (для интеграции с бухгалтерией / 1С) |

**Категории меток (`category`):**

| Категория        | Смысл                                        | Расчёт часов            |
| ---------------- | -------------------------------------------- | ----------------------- |
| `work`           | Явка, работа                                 | Часы из турникетов      |
| `paid_absence`   | Оплачиваемое отсутствие (отпуск, больничный) | Часы = норма по графику |
| `unpaid_absence` | Неоплачиваемое отсутствие (АО, за свой счёт) | Часы = 0                |
| `violation`      | Нарушение (прогул)                           | Часы = 0                |
| `day_off`        | Выходной / праздник                          | Не учитывается          |

**Пример из текущей системы:**

| shortName | name                    | code | category       | reportCode |
| --------- | ----------------------- | ---- | -------------- | ---------- |
| Я         | Явка                    | I    | work           | —          |
| Н         | Ночная                  | N    | work           | —          |
| ОТ        | Отпуск                  | OT   | paid_absence   | 27         |
| ОД        | Отпуск по уходу         | OD   | paid_absence   | 27         |
| Б         | Больничный              | B    | paid_absence   | 24         |
| АО        | Административный отпуск | AO   | unpaid_absence | —          |
| ПР        | Прогул                  | PR   | violation      | —          |
| В         | Выходной                | W    | day_off        | —          |

### 2.7. Шаблон производственного календаря (`calendar_template`)

Правительственное постановление о переносе праздников — на год.

| Поле              | Тип       | Примечание                                                                    |
| ----------------- | --------- | ----------------------------------------------------------------------------- |
| `name`            | `text`    | Название (например «Производственный календарь 2025»)                         |
| `year`            | `integer` | Год                                                                           |
| `defaultWorkDays` | `integer` | Дни недели, считающиеся рабочими по умолчанию (битовая маска или массив, 1–7) |
| `defaultWorkTime` | `integer` | Стандартная норма часов на рабочий день (мин)                                 |

### 2.8. День производственного календаря (`calendar_day`)

| Поле             | Тип                                                                                         | Примечание                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `template (ref)` |                                                                                             |                                                                                                  |
| `date`           | `date`                                                                                      | Конкретная дата                                                                                  |
| `dayType`        | `text`                                                                                      | `workday` / `holiday` / `preholiday` / `weekend` / `transferred_workday` / `transferred_holiday` |
| `schedule (ref)` | nullable. Если указан — применяется этот график (например сокращённый для предпраздничного) |
| `workTime`       | `integer`                                                                                   | Норма часов на этот день (мин). Если null = `defaultWorkTime`                                    |
| `transferFrom`   | `date`                                                                                      | nullable. Если день — перенос, то откуда перенесён                                               |

**Логика переносов:**

1. Праздник выпадает на СБ/ВС → `dayType = holiday` на эту дату
2. Включается `transferFrom` → создаётся запись с `dayType = transferred_holiday` на понедельник (или дату по постановлению)
3. Предпраздничный день (последний рабочий перед праздником) → `dayType = preholiday`, норма сокращается (обычно −1ч)
4. На `preholiday` и `transferred_workday` можно задать отдельный `schedule (ref)` с сокращённым графиком

## 3. Ключевые бизнес-правила

### 3.1. Историчность

Кадровые документы фиксируют все изменения. Перевод 15-го числа → сотрудник числится в двух подразделениях за месяц: до 15-го и с 15-го.

### 3.2. Сотрудник без документа

Нет приказа о приёме → нет записи в табеле.

### 3.3. Обработка событий с турникетов

1. Загрузка Excel → `turnstile_event_tracker`
2. Для каждой пары Вход→Выход:
   - Выбор графика (если несколько — балльная оценка)
   - Округление по границам
   - Вычет перерывов
   - Расчёт ночных часов
3. Результат → `worktime_tracker.raw*` + `worktime_tracker.shift*`

### 3.4. Расчёт ночных часов

Ночное время: `NIGHT_SHIFT_START`–`NIGHT_SHIFT_END` (22:00–06:00).

### 3.5. Производственный календарь

Определяет по дате: рабочий день / выходной / праздник / предпраздничный. Норма часов на день — из календаря (если не задана — из графика). Применяется при расчёте `shift*` и для сверки с нормой.

### 3.6. Аудит

На таблицах `document` и `worktime_tracker` — `updatedAt` (авто) и `updatedBy` (из сессии).

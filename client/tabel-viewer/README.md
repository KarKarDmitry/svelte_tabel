# tabviewer — вьювер табеля для Windows XP

Автономный клиент только для просмотра табеля (без права редактирования),
работает на Windows XP без установки чего-либо (один .exe, системные библиотеки).

## Возможности
- Вход по логину/паролю (better-auth); сессия сохраняется в `token.txt` рядом с exe
- Табель на месяц: т/н, ФИО, Итого, Ночь, дни месяца (в две строки — часы и отметки)
- Переключение месяца (◀ ▶, «Сегодня»)
- Чекбокс «Факт. время»: показывает часы факта импорта турникета вместо отчётных
- Расцветка ячеек — порт `cell-style.ts` (пропуски, переработка/недоработка, работа в выходной)
- Диалог «События сотрудника» по двойному клику на строке (турникет-события + отметки по дням)

## Сборка (на dev-машине, не на XP)
Требуется MinGW-w64 (`gcc` в PATH):

```
client\tabel-viewer\build.cmd
```

Результат — `tabviewer.exe`.

## Конфигурация
Рядом с exe положить `config.txt` (см. `config.txt.example`):

```
server=http://192.168.1.242:8080
email_domain=mettem.com
```

Логин вводится без домена: к нему добавляется `@email_domain`.

## Серверная часть
- `GET /apps/tabel/tabel/month?year=&month=` — данные месяца (создано для вьювера)
- `GET /apps/tabel/tabel/employee-events?employeeId=&year=&month=` — события и отметки
  (используется диалогом; нативным аналогом является `EmployeeEventsNative`)

## Раскладка
- `json.c/h` — мини JSON-парсер (без зависимостей)
- `net.c/h` — HTTP поверх WinINet (sign-in, set-cookie, GET)
- `model.c/h` — парсинг JSON месяца/событий + порт cell-style.ts
- `main.c` — окно табеля, сетка, навигация, логин
- `events.c` — диалог событий сотрудника
